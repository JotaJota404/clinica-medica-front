# 🏥 Clínica Médica - Interface de Gestão Hospitalar

> **Status do Projeto:** Em desenvolvimento (Integração com Backend) 🚀

Este projeto faz parte de uma solução robusta de gestão para a **Clínica Médica**. Como responsável pelo **Frontend**, meu foco foi unir a estética visual (bagagem de 7 anos em Design) com a funcionalidade técnica necessária para um ambiente hospitalar dinâmico.

---

## 🎨 Design & Sensibilidade Visual

Diferente de interfaces genéricas, este projeto foi construído do zero focando na "Vibe Coding":
* **UI/UX:** Layout limpo, tipografia legível (Montserrat) e paleta de cores que transmite confiança e higiene.
* **Microinterações:** Uso de animações suaves de scroll e hover para guiar a atenção do usuário.
* **Responsividade:** Estrutura adaptável para desktops e dispositivos móveis (Grid & Flexbox).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica para melhor SEO e acessibilidade.
* **CSS3:** Estilização avançada com variáveis nativas e animações customizadas.
* **jQuery:** Manipulação de DOM para efeitos de interatividade e Smooth Scroll.
* **Figma:** Prototipação prévia para validação de fluxos.

---

## 🏗️ Arquitetura do Frontend

O projeto está organizado para facilitar a manutenção e escalabilidade:
* `/assets`: Ícones, logos e imagens otimizadas.
* `/css`: Estilos globais e componentes específicos.
* `/js`: Lógica de interatividade da interface.
* **Telas Implementadas:**
    * `index.html`: Landing page institucional com foco em conversão.
    * `login.html`: Portal de acesso seguro.
    * `admin.html`: Painel de controle administrativo.
    * `atendimento.html` / `pacientes.html`: Telas operacionais do sistema.
